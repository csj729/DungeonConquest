# 수직 슬라이스 카드 풀 — 공통 각인 · 유물

`design.md` §4에서 정의한 카드 계열 중 **직업 무관 공용 풀**을 채운다. 직업별 고유
각인은 `heroes_vertical_slice.md`에, 조합 지원 카드는 아이템 축과 함께 다룬다.

**이 풀이 8직업으로 곱해지지 않는다는 점이 중요하다.** 스킬·고유 각인은 직업 수만큼
늘어나지만 여기 있는 것들은 고정 비용이므로, 콘텐츠 스코프의 안전판 역할을 한다.

각 항목의 **유형**은 §4의 구분을 따른다 — 수치형은 §9 모디파이어 그대로, 훅형은
지정된 이벤트 훅에 등록된다.

---

## 1. 공통 각인 — 8종

모든 스킬에 부착 가능하다. **고급·희귀 두 등급에서 나오며, 같은 각인이 등급에 따라
수치만 달라진다.** 등급별로 다른 각인을 따로 만들지 않는다 — 데이터가 두 배가 되고
얻는 게 없다.

| ID | 이름 | 효과 | 유형 | 훅 |
|---|---|---|---|---|
| `E_PIERCE` | **관통** | 적을 뚫고 지나가 뒤의 적도 맞힌다 | 훅형 | `onHit` |
| `E_SPLIT` | **분열** | 적중 시 파편이 인접한 적에게 튄다 | 훅형 | `onHit` |
| `E_LEECH` | **흡혈** | 준 피해의 일부를 체력으로 회복한다 | 훅형 | `onHit` |
| `E_BURST` | **작렬** | 이 스킬로 처치한 적이 폭발한다 | 훅형 | `onKill` |
| `E_STAGGER` | **진동** | 짧은 기절을 추가한다 | 훅형 | `onHit` |
| `E_WIDE` | **확장** | 광역기는 반경이, 단일기는 사거리가 늘어난다 | 수치형 | — |
| `E_FOCUS` | **집중** | 이 스킬의 추첨 가중치가 오른다 | 수치형 | — |
| `E_REND` | **파쇄** | 대상 `Armor`를 일정 비율 무시한다 | 수치형 | — |

### 설계 메모

- **`E_REND`는 방패병(`GE_SHIELD`)의 직접적인 해답이다.** §9의 비율 감쇠 공식과 맞물려,
  실효 체력 300짜리를 상대할 수단을 각인 쪽에도 열어둔다
- **`E_FOCUS`는 §3의 가중 추첨에 직접 개입한다.** 통합 proc 확률(발동 빈도)과 스킬
  가중치(무엇이 나오는가)가 분리돼 있으므로, 각인이 후자만 건드릴 수 있다
- **`E_STAGGER`는 일반 몹과 엘리트에게 다르게 작동한다.** 일반 몹은 즉시 기절하지만
  엘리트·보스는 CC 게이지를 채운다 (`monsters_vertical_slice.md` §4)
- 여덟 개 전부 전사의 액티브 3종 어디에 붙여도 말이 된다 — 이게 "공통" 각인의 조건이다

## 2. 유물 — 일반 6종

**스킬과 무관하게 독립 작동한다.** 각인이 스킬의 성질을 바꾸는 것과 달리, 유물은
전장에 규칙을 하나 더한다. 고급·희귀 등급에서 나온다.

| ID | 이름 | 효과 | 훅 |
|---|---|---|---|
| `R_THORN` | **가시 갑주** | 피격 시 공격자에게 반사 피해 | `onDamaged` |
| `R_RAGE` | **분노의 토템** | 피격당할수록 공격력 증가 (중첩, 상한 있음) | `onDamaged` |
| `R_MEND` | **치유의 성물** | 적 처치 시 소량 회복 | `onKill` |
| `R_BOLT` | **뇌전의 성물** | 주기적으로 무작위 적에게 번개 | `onTick` |
| `R_FROST` | **서리 오라** | 주변 적의 이동 속도를 늦춘다 | `onTick` |
| `R_MAGNET` | **자력 장** | 주변 적을 천천히 끌어당긴다 | `onTick` |

### 설계 메모

- **`R_MAGNET`이 물량전과 가장 잘 맞는다.** 적을 모아주면 광역기 한 방에 걸리는 수가
  늘어난다 — 검산에서 "광역기가 평균 3마리를 함께 정리한다"고 가정한 값을 직접 끌어올린다
- **`R_THORN`과 `R_RAGE`는 피격을 자원으로 바꾼다.** 자동 전투라 피격을 회피할 수단이
  없으므로, 맞는 것 자체에 보상을 붙이면 생존 축 빌드에 방향이 생긴다
- `onTick` 유물 셋은 전부 주기 실행이라 **틱 카운터 기반**이다. 실시간 참조가 없어
  결정론에 안전하다

## 3. 전설 유물 — 3종

전설 등급에서 고유 각인과 **같은 확률 풀을 공유한다** (§4). 판의 규칙을 바꾸는 급이다.

| ID | 이름 | 효과 |
|---|---|---|
| `RL_ECHO` | **무한의 메아리** | 기본 공격의 proc 판정이 **1회 더** 굴러간다 |
| `RL_STORM` | **폭풍의 핵** | 영웅 주위를 상시 회전하는 칼날 — 지속 광역 |
| `RL_FORGE` | **대장장이의 화로** | 웨이브 종료 시 흔함 아이템 1개를 자동 획득 |

### `RL_ECHO`가 QTE 쿨다운을 실제로 작동시킨다

proc 15%가 두 번 굴러가면 실효 발동률이 약 27.75%가 된다. 기준선에서 웨이브당 스킬
발동이 3.7회였던 것이 **약 6.8회로 뛴다.**

여기서 §3의 QTE 쿨다운(6초)이 상한을 잡아 4.1회로 제한한다. **"공속이 1.3배 오르면
작동하는 안전장치"라고 적어둔 장치가 실제로 걸리는 첫 사례다** — 쿨다운을 안 뒀다면
이 유물 하나가 QTE 예산을 두 배로 터뜨렸을 것이다.

### 나머지 둘

- **`RL_STORM`**: 스킬 발동과 무관하게 상시 딜이 들어간다. proc 운이 나쁜 판을
  구제하는 성격이라 §7 ③("확정 요소를 주력, 확률 요소를 보너스로")과 결이 같다
- **`RL_FORGE`**: 조합 축을 가속한다. 조합 지원 카드는 전설 등급을 갖지 않으므로(§4),
  그 자리를 전설 유물이 대신한다

## 4. 전설 풀 구성

| 출처 | 개수 |
|---|---:|
| 고유 각인 (전사 기준) | 6 |
| 전설 유물 | 3 |
| **합계** | **9** |

전설이 떴을 때 **무엇이 나올지 모른다**는 점이 잭팟의 기댓감을 만든다 (§4). 직업이
늘어도 전설 유물 3종은 고정이므로, 직업별 고유 각인만 더해지는 구조다.

---

## 5. 남은 것

- **수치 전부 미정** — 각인의 고급/희귀 등급별 수치, 유물 효과량, `onTick` 유물의
  발동 주기, `R_RAGE` 중첩 상한
- 카드 등급별 등장 확률과 각인 슬롯 수는 §15 미결정 (몬테카를로로 함께 정한다)
- **훅 다섯 종류의 실행 순서 검증**이 필요하다. 같은 훅에 여러 효과가 걸릴 때 ID
  오름차순으로 고정하기로 했으나(§4), 재현성 테스트로 실제 확인해야 한다
- 조합 지원 카드 목록 — 아이템 축과 함께 별도로 정한다
