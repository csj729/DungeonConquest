# 수직 슬라이스 아이템 조합 트리

> `design.md` §5의 다경로 원칙을 실제 데이터로 구현한 결과물.
> 결정 사항이 아니라 **콘텐츠 데이터**이므로 `design.md`와 분리해 여기 기록한다.
> 수치는 전부 자리표시자(illustrative)다. 실제 값은 §14 몬테카를로 하네스로 정한다.

## 근거 — 원랜디(원피스 랜덤 디펜스) 조합 구조

- 흔함은 뽑기로만 획득, 안흔함 이상은 전부 조합으로 제작
- 상위 조합일수록 재료 수가 늘어나는 패턴 (RID 예시: 특별함 3개 → 희귀함)
- **동일 등급 아이템 3개를 모으면 2단계 위 등급으로 직행**하는 지름길 조합이 존재한다.
  이번 개정에서 이 패턴을 채택했다 (아래 "3연성 스킵")

## 개정 이력

이전 판은 "등급이 올라갈수록 아이템 수가 엄격히 감소"를 강제해 축(화력·CC·광역·생존)당
3경로를 못 채웠다. **그 제약을 없앴다.** 다경로 확보가 우선이며, 상위 등급이 하위보다
많아져도 된다. 그 결과 **4축 전부 정확히 3경로**를 달성했다 (아래 §7).

---

## 등급 구조 (확정)

```
흔함(9) → 안흔함(12) → 특별함(8) → 희귀함(10) → 전설적인(12)
```

개수가 등급마다 늘거나 줄거나 한다 — **감소를 강제하지 않는다.** 51종, 42개 조합식.
히든 이상 4등급은 이번 수직 슬라이스 범위 밖이다.

### 3연성 스킵 (동일 등급 3개 → 2단계 위)

동일한 아이템 3개를 모으면 **데이터로 지정된, 2등급 위의 특정 아이템 하나**로 직행한다.
결과는 고정값이다 — 확률로 상위 등급이 나오는 경로는 여전히 존재하지 않는다
(§5 획득 규칙 유지). `RecipeData { result, ingredients[] }`에 같은 ID를 3번 넣으면
표현되므로 **스키마 변경이 없다.**

이 트리에는 4개의 스킵 레시피가 있다 (안흔함→희귀함 2개, 특별함→전설적인 2개).
평소에 비주력으로 취급되던 아이템(질풍의 낙뢰, 독니 박힌 갑주 등)에게
"3개 모으면 그 자체로 목표가 된다"는 별도 가치를 준다.

## 8. 남은 것

- **수치 밸런싱** — 모든 효과·수치는 자리표시자. §14 몬테카를로 하네스로 확정
- **뽑기 가중치** — C9(정령의 눈물)의 희소성을 흔함 내 가중치로 표현할지 결정 필요
- **3연성 스킵의 파밍 비용** — 스킵 대상(질풍의 낙뢰 등)을 3개 모으는 데 필요한 기대
  시행 횟수가 일반 조합 경로보다 유리한지 불리한지 밸런싱 대상. 유리하면 일반 경로가
  무의미해지고, 불리하면 스킵이 죽은 기능이 된다
- **히든 이상 4등급** — 이번 범위 밖. 51종 규모가 이미 상당하므로 확장은 신중히
- **아이템 51종의 구체 효과 수치** — 현재 이름과 축만 확정. `ItemData.baseStats` /
  `grantedAbility` 값은 밸런싱 단계
